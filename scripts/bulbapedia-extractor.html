📚 Bulbapedia JP card extractor

把下面这个红色按钮 拖到浏览器收藏栏:

📥 Extract JP cards

看不到进度? 这版会在页面 右上角弹一个黑色浮窗,每张卡都打日志。 如果连浮窗都没出 → 打开 DevTools (Cmd+Option+I) 看 Console 报错。

怎么用

  1. 把红按钮 拖到收藏栏
  2. 访问 Bulbapedia set 页,等 Cloudflare 验证过
  3. 建议先打开 DevTools (Cmd+Option+I) → Console tab,这样有问题能看到
  4. 点收藏栏的 📥 按钮
  5. 右上角应该立刻出现黑色浮窗,先打印 "selector hit"+"Parsed N cards" — 如果 N=0 就是页面表格结构不匹配,告诉我
  6. 然后逐张卡打 ✓ 或失败原因。M1L 92 张约 1.5-2 分钟
  7. 完成后自动下载 jp-cards-megabrave.json
  8. 挪到 ~/poke/, 跑: 
    cd ~/poke
node scripts/download-jp-cards-from-json.js m1l jp-cards-megabrave.json
  9. git push, Vercel 部署
