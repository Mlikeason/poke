📚 Bulbapedia JP card extractor

把下面这个红色按钮 拖到浏览器收藏栏:

📥 Extract JP cards

怎么用

  1. 把上面红按钮 拖到收藏栏(Bookmarks Bar)。Chrome / Safari / Firefox 都行
  2. 在浏览器打开 Bulbapedia 的 set 页, 例如:
    https://bulbapedia.bulbagarden.net/wiki/Mega_Brave_(TCG)
  3. 等 Cloudflare 验证过去, 看到完整 wiki 页面
  4. 点收藏栏上的 📥 Extract JP cards
  5. 等它跑完(每张卡进详情页拿原图 URL, 一张约 1 秒, M1L 92 张 ≈ 1.5 分钟)。浏览器 tab 标题会显示进度
  6. 跑完自动弹一个 alert + 下载一个 jp-cards-XXX.json 文件
  7. 把 JSON 文件挪到 ~/poke/ 根目录
  8. 在终端跑: 
    cd ~/poke
node scripts/download-jp-cards-from-json.js m1l ./jp-cards-megabrave.json
    (第一个参数是 setId, 第二个是 JSON 文件路径)
  9. 会下到 public/cards/jp/m1l/<编号>.jpg 并更新 manifest
  10. commit + push, Vercel 自动部署后 app 里就能看到
